# Build from the confirmed brief

Read this only after the user has confirmed the brief.

1. **Build** with `arcadia-method` and `capella-model-edits`. Every value of team knowledge goes into
   the model where a reader looks for it: a constraint on the element it limits, or the name or
   description of the part it identifies. Done when every brief line maps to a native element.
2. **Record assumptions** as a TBD constraint on the element each one affects, with the recommended
   value. Done when every deferred decision in the brief has its TBD.
3. **Report** what was built against the brief, line by line, and anything left open.
